## package structure description

### chartspy

Currently wraps echarts, g2plot, KLineChart, HighCharts, Tabulator corresponding to 5 objects

#### Echarts 

**parameters:**
```python
"""
:param options: python dict type echarts option
:param extra_js: complex chart may need extra functions, use this parameter
:param with_gl: whether to load echarts-gl extension for 3D charts
:param width: output div width  support pixel and percent like 800px/100%
:param height: output div height  support pixel and percent like 800px/100%
"""
```

**output:**

render_notebook() notebook

render_jupyterlab() jupyterlab

render_html() complete html

render_html_fragment() html fragment for multiple charts on one page

dump_options() print js configuration (used for copy and paste)

print_options() formatted print of options for modification

**static methods:**

timeline() timeline animation chart

**instance methods:**

overlap_series() overlay series data from other configurations

#### Tools 

Tools static methods:

* convert_js_to_dict JavaScript configuration convert to python dict
* convert_dict_to_js python dict convert to JavaScript configuration
* convert_to_list help user convert DataFrame, Series, ndarray into list
* df_uniformize_datetime_columns uniformize datetime columns in DataFrame
* df2tree convert DataFrame to tree structure for echarts

### chartspy.express

pandas DataFrame visualization functions, learn from plotly.express

#### Echarts charts

include scatter, line, bar, pie, candlestick, heatmap, calendar_heatmap, parallel, radar, theme_river, sankey, sunburst, scatter3d, bar3d, drawdown etc.

#### G2Plot charts

include area, bullet, chord, waterfall, liquid, wordcloud, column_stack, column_stack_percent, treemap etc.

#### HighCharts charts

include streamgraph, dependency_wheel, arcdiagram etc.
